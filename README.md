# CodeAlpha_IrisFlowerClassification

- Make a internship project for CodeAlpha. In this project we make a machine learning model Logistic Regression predict for  Species of the iris flower.

- I created this project for the CodeAlpha internship. Here i will tell you the complete details of the project.
- I enrolled in an internsship through the CodeAlpha website and selected Data Science as my domain.
- I am grateful to CodeAlpha for giving me the experience of working at an industry level.
- I worked on the Iris Flower dataset, If you need this dataset, you can download it from my GitHub.
- While working on this project, the first thing i did was create .ipynb file. I explored the dataset using descriptive statistics. I observed that the dataset is besed on three different species, (Setosa,Versicolor,Virginica). This dataset had six columns Id, SepalLengthCm, SepalWidthCm, PetalLengthCm, PetalWidthCm, Species. The Species have been classified based on Sepal length & width and Petal length & width.
- I Observed that there was no missing data in this dataset.
- we too observed through visualization that these three species appeared distinct from one another.
- We decided to develop a Supervised Machine learning model here that predicts the species type when the sepal length & width and petal length & wwidth are enterd.
- Species is Categorical/Object datatype Machine can't undarstand text. First of all this species text convert into numbers with the help of scikit-learn LabelEncoder.
- We train Supervised Machine Learning Logistic Regression Model that's why dataset divide into train and test datasets.
- After train and evaluate the model we save the Logistic Regression Model and also LabelEncoder.
- After that we create app.py file for build a streamlit application with help of python and streammlit framework from which we can make predictions.
Application show 4 Input Features Sepal Length (cm), Sepal Width (cm), Petal Length (cm), Petal Width (cm), show a sidebar select a length and width than Clink on Species Predictor button show the result base on your selection.
I create requirements.txt file for all necessary libraries with versions. I upload this application on streamlit platform you can easily accessible for everyone.
